# The Great Warwick Game Jam

We are making a short deep ocean roguelike survival game inspired by Barotrauma. The theme of the
jam is 'no time to explain' which inspires the opening scene where the player has 30 seconds to
equip themselves with a limited number of items from an exploding submarine. Ideally, the items the
player chooses dictate the success or failure of their run.
